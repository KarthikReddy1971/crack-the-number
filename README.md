# 🎯 Crack The Number

A modern interactive number-guessing game built with **React, TypeScript, Vite, and Tailwind CSS**.

Guess the secret number before your 10 attempts run out. Use smart hints, track your guesses, manage your score, and crack the number! 🔥

## 🚀 Live Demo

👉 Add your deployed link here

## ✨ Features

- 🎯 5 difficulty levels — 1–50 to 1–1000
- 🧠 Too High / Too Low + closeness feedback
- 💡 Progressive hints with score deduction
- 🏆 Score system starting at 1000
- 🔢 10 attempts per game
- 📜 Previous guess history
- 🎉 Animated victory & balloon celebration
- 💀 Game-over screen
- 📱 Fully responsive for mobile & desktop
- ✨ Custom CSS animations and interactive UI

## 🛠️ Tech Stack

- **React** — UI & application state
- **TypeScript** — type-safe game logic
- **Vite** — development & build tool
- **Tailwind CSS** — responsive styling
- **CSS** — custom animations & effects
- **Git & GitHub** — version control
